# LazyCoders Portfolio

A team portfolio website built with Node.js, Express, EJS, TailwindCSS, and PostgreSQL.

## Tech Stack

- Node.js
- Express.js
- EJS (templating)
- TailwindCSS

## Team Members

## Features

- Home page with team member profiles
- Projects page showcasing work
- Dark mode toggle
- Mobile responsive
- Visitor counter

## Local Setup

### Prerequisites

- Node.js 18 or higher

### Steps

1. Clone the repository
2. Run `npm install`
3. Run `npm start`
4. Visit `http://localhost:3000`
